# Kassi Deutsch

Ein mobiler deutsch–estnischer Vokabeltrainer für Niveau A1–A2. Kurze tägliche Lernrunden halten eine virtuelle Katze am Leben.

## Funktionen

- 200 Alltagswörter in zehn Themen
- gemischte Multiple-Choice- und Texteingabe-Aufgaben
- kostenlose deutsche Aussprache über die Stimme des Geräts
- sieben Katzenherzen, XP, Level und Rettungsrunde
- eigene Wörter und Fortschritt lokal im Browser gespeichert
- zweisprachige, für iPhone-Safari optimierte Oberfläche

## Lokal starten

```bash
pnpm install
pnpm dev
```

## Prüfen

```bash
pnpm test
pnpm build
```

Jeder Push auf `main` veröffentlicht die statische App automatisch über GitHub Pages.
